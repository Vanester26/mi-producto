# T1 · Planilla de recolección del equipo

Una fila por dato capturado. Registre la hora de cada captura.
El equipo usa esta planilla para detectar los cambios. El analista no la ve.

## Columnas

| Columna | Qué escribir |
|---|---|
| fecha_captura | AAAA-MM-DD |
| hora_captura | HH:MM, hora local del analista |
| analista | ID de la `lista-rutas.md` (A1, A2, …) |
| ruta | ORIGEN-DESTINO |
| competidor | Nombre |
| dato | `tarifa` · `horario` · `frecuencia` |
| fecha_salida | AAAA-MM-DD (solo para tarifa y horario) |
| d_n | `D-7` · `D-14` · `D-30` (solo para tarifa) |
| valor_hoy | Ej. `USD 89`, `07:40 (XX123)`, `5 por semana`, o `sin dato` |
| valor_ayer | Valor de la captura anterior para la misma fecha de salida |
| cambio | `sí` · `no` · `sin dato` |
| id_cambio | Solo si cambio = sí. Formato `{analista}-D{día}-{n}` |
| fuente | URL usada |
